# Infinite Studio Pro

A small game design engine prototype built with React + Vite.

Features included:
- Block coding palette
- JavaScript scripting workspace
- Drag-and-drop sprite placement
- Custom sprite uploads
- 3D mode toggle
- Ambient sound generator
- HTML / HTA / APK export scaffolding

## Quick start

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Export notes

- HTML export creates a standalone browser package.
- HTA export creates a Windows HTML Application shell.
- APK export creates a starter Android manifest scaffold for further Android packaging.

## Project intent

This repo is a starter engine for building your own game design studio: a visual editor, a script panel, and a scene layout with drag-and-drop object placement.
